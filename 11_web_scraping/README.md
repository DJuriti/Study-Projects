# Web Scraping de Livros com Python 📚

## Sobre o Projeto

Este projeto foi desenvolvido em Python com o objetivo de praticar conceitos de Web Scraping, coletando informações de livros através de uma página web, realizando tratamento dos dados e exportando os resultados para uma planilha Excel.

O programa permite selecionar uma categoria de livros, acessar o site, extrair informações dos produtos e gerar uma tabela organizada com os dados coletados.

---

## Funcionalidades

- Coleta de livros através de Web Scraping;
- Seleção de categoria de livros;
- Extração de informações como:
  - Título;
  - Preço em libra;
  - Conversão do preço para reais;
  - Avaliação;
  - Disponibilidade;
- Organização dos dados utilizando Pandas;
- Exportação dos resultados para arquivo Excel.

---

## Tecnologias Utilizadas

- Python;
- Requests;
- BeautifulSoup;
- Pandas;
- Openpyxl.
