# CRUD de Produtos com Python e SQLite 🗄️

## Sobre o Projeto

Este projeto foi desenvolvido em Python com o objetivo de praticar integração com banco de dados utilizando SQLite.

O sistema permite realizar o gerenciamento de produtos através de um menu interativo, armazenando as informações de forma persistente em um banco de dados.

O projeto implementa as operações CRUD:

- Create (Cadastrar)
- Read (Consultar)
- Update (Atualizar)
- Delete (Excluir)

---

## Funcionalidades

- Cadastro de produtos;
- Listagem de produtos cadastrados;
- Atualização de informações;
- Exclusão de produtos;
- Armazenamento permanente dos dados utilizando SQLite;
- Organização do código em módulos.

---

## Tecnologias Utilizadas

- Python;
- SQLite;
- Biblioteca sqlite3.
